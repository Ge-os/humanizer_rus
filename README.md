# humanizer_rus

Гуманизация русских AI-текстов: каждый n-й значимый токен (не стоп-слово) заменяется на синоним
из словаря, который контекстно подходит по мнению модели ранжирования. Цель — повысить
непредсказуемость текста (перплексию), чтобы обходить AI-детекторы, работающие на перплексии.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows; Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -c "import nltk; nltk.download('stopwords'); nltk.download('extended_omw')"
```

Словарь синонимов: положите `synonims.parquet` (датасет
[d0rj/russian-synonyms](https://huggingface.co/datasets/d0rj/russian-synonyms/)) в `data/`.

## Запуск

```bash
python -m app.cli --input in.txt --output out.txt --model lesk --n 2 --mode 2 --threshold 0.25
```

| флаг | по умолч. | описание |
|---|---|---|
| `--input`, `--output` | — | файлы на вход/выход (utf-8) |
| `--model` | `ngram` | модель ранжирования: `lesk`, `ngram`, `pmi` |
| `--n` | 1 | заменять каждый n-й значимый токен |
| `--mode` | 2 | 1 — случайный из прошедших порог, 2 — самый вероятный, 3 — наименее вероятный (максимум перплексии) |
| `--threshold` | 0.5 | порог вероятности кандидата для замены |
| `--seed` | — | seed для режима 1 |
| `--context` | `sentence` | контекст ранжирования: `sentence` или `window` |
| `--window` | 10 | размер окна в словах для `--context window` |
| `--max-candidates` | 10 | максимум кандидатов вместе с оригиналом |
| `--corpus` | — | корпус (предложение в строке) для обучения `ngram`/`pmi` |
| `--models-dir` | `models` | кэш обученных артефактов |
| `--synonyms` | `data/synonims.parquet` | словарь синонимов |
| `--report` | — | JSON-отчёт с решениями по каждому токену |

Алгоритм: токенизация (razdel) → отбор каждого n-го не-стоп-слова → кандидаты
`[оригинал, синонимы...]` (синонимы склоняются pymorphy3 под форму оригинала) → ранжировщик
возвращает вероятности (softmax) → если прошёл порог не-оригинальный кандидат, ставится он
(режим 1/2), иначе остаётся оригинал.

## Архитектура

- `app/text.py` — токенизация, стоп-слова NLTK, морфология pymorphy3.
- `app/synonyms.py` — словарь синонимов из parquet (по слову и лемме, с кэшем индекса).
- `app/rankers.py` — `BaseRanker` и реализации (`lesk`, `ngram`, `pmi`); модель меняется
  одним флагом `--model` через `REGISTRY`.
- `app/policy.py` — порог и режимы выбора.
- `app/humanizer.py` — оркестрация и сборка текста.
- `app/cli.py` — командная строка.

## Исследование

Прогоны, метрики и выводы — в ветке `research` (каталог `research/`, итоги в
`research/RESULTS.md`, все тексты и логи в `research/results/`). Текущий лидер по росту
перплексии — `lesk` (n=1, порог 0.25); `ngram`/`pmi` в текущей постановке перплексию снижают
(подробности и рекомендация режима 3 — в `research/RESULTS.md`).

## Ограничения

- Словарь синонимов шумный; качество замен сильно зависит от порога и `--n`.
- Метрики исследования — прокси; финальная проверка реальными детекторами выполняется отдельно.
